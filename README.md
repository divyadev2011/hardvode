# Weekend Trips

A small, one-page travel website made with HTML and CSS. The page has a few sections, simple landscape pictures, and links that scroll to each section.

## Open the website

1. Download or clone this repository.
2. Open `index.html` in a web browser, such as Brave.

The website is self-contained: its styles and pictures are included in `index.html`, so you only need that file to view it.

## Change the website

Open `index.html` in a text editor to change the page title, words, links, or pictures. The section menu links use IDs such as `about`, `places`, and `contact`. Keep each link's `#name` matched to a section's `id="name"` so the scrolling links continue to work.

## Built with

- HTML
- CSS
- SVG illustrations
